# TL-1 local-model benchmark — Professional Summary

Task: tailor the 3-line Professional Summary for 3 saved JDs
(`agent/bench/jds/`) from one master CV (`agent/bench/master_cv.txt`), with JSON
mode via Ollama's `format`. Metrics per model: tokens/sec (from Ollama's own
`eval_count` / `eval_duration`), wall time per summary, peak RAM, JSON-validity
rate, and the honesty rate (every number in the output must appear in the master
CV — `summary_numbers_supported`).

> **Status: PROJECTED, not yet measured.** The 23 Nov run hit the Claude weekly
> limit, and the TL-1R build ran in an environment with **no Ollama installed**
> (and no dedicated GPU), so these numbers are a reasoned estimate for the target
> hardware, not a measurement. Run `python -m agent.bench.tailor_bench` on
> Shekar's PC with the models pulled and it **overwrites this file** with the
> real table. The recommended default below is a safe starting point meanwhile.

Target hardware (measured on this PC, 25 Nov 2026): Intel Core i7-8650U
(4 cores / 8 threads, ~1.9 GHz), 16 GB RAM, Intel UHD 620 integrated graphics —
**no dedicated GPU / VRAM**, so inference is CPU-only.

## Recommended default

**`qwen2.5:7b-instruct-q4_K_M`.** Reasons:

1. **Best instruction-following at 7B for strict JSON.** The summary task runs in
   Ollama `format` (JSON-schema) mode; Qwen2.5-Instruct is the most reliable of
   the three at returning schema-valid JSON on the first try, which is what keeps
   the honesty check and the preview working without retries.
2. **Fits CPU-only with headroom.** At Q4_K_M it is ~4.7 GB on disk and ~5 GB
   resident — comfortable inside 16 GB while Chrome and the OS are also running
   (the machine had ~2 GB free at probe, so a smaller footprint matters).
3. **Fastest of the three on CPU.** 7B beats the 8B and 9B candidates on
   tokens/sec with no GPU, and a summary is short (~512 output tokens), so the
   wall time stays tolerable (tens of seconds).
4. **Quality is enough for a 3-line summary.** The honesty guarantee is enforced
   in code either way (`summary_numbers_supported`), so the model only has to
   phrase real facts well — a job 7B handles.

Fallback if Qwen's JSON ever regresses: `llama3.1:8b-instruct-q4_K_M` (similar
footprint, slightly slower, also strong). `gemma2:9b` is the heaviest and its
`format` adherence was the least reliable in community reports, so it is not the
default.

This default is mirrored in code: `DEFAULT_LOCAL_MODEL` in `src/lib/llm/index.ts`
and `DEFAULT_MODEL` in `agent/worker/config.py`. If the measured run picks a
different winner, update both.
